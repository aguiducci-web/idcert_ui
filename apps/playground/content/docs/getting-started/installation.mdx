`@idcert/ui` ships as three packages on the internal Verdaccio registry. The `ui` package is the React component library; `@idcert/tokens` provides CSS variables; `@idcert/tailwind-config` is a Tailwind v4 preset that wires variables to utility classes. Installing `@idcert/ui` pulls the other two transitively.

## Prerequisites

- Node ≥ 18
- React 18+ and Next.js 14+
- Tailwind CSS v4

## 1. Install packages

A single command pulls `@idcert/ui` plus its transitive dependencies (`@idcert/tokens`, `@idcert/tailwind-config`). Peer dependencies (`tailwindcss`, `react`, etc.) auto-install with npm 7+ or pnpm when `auto-install-peers=true`.

<CodeBlock language="bash">{`npm i @idcert/ui --registry=http://localhost:4873/`}</CodeBlock>

Then add the Tailwind v4 PostCSS plugin (required by Next.js):

<CodeBlock language="bash">{`npm i -D @tailwindcss/postcss`}</CodeBlock>

## 2. PostCSS config

Create `postcss.config.mjs` at the project root:

<CodeBlock language="js">{`export default {
  plugins: { '@tailwindcss/postcss': {} },
}`}</CodeBlock>

## 3. Wire Tailwind

Tailwind v4 uses a CSS-first preset — no `tailwind.config.js` needed. Import the preset into your global stylesheet.

`app/globals.css`:

<CodeBlock language="css">{`@import 'tailwindcss';
@import '@idcert/tokens/styles.css';
@import '@idcert/tailwind-config/preset.css';

@source '../node_modules/@idcert/ui/dist';`}</CodeBlock>

The `@source` directive tells Tailwind v4 to scan the published `dist` for utility usage. **Without it, classes used internally by components (e.g. `bg-destructive`) are purged and components render unstyled.** Adjust the relative path if your `globals.css` lives in `src/app/` (`'../../node_modules/@idcert/ui/dist'`).

Import order matters: tokens first (defines `--destructive`, `--primary`, …), preset second (maps vars to theme utilities).

## 4. Wrap your root layout

`app/layout.tsx`:

<CodeBlock language="tsx">{`import './globals.css'
import { ThemeProvider, ToastProvider, Toaster } from '@idcert/ui'

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body className="bg-background text-foreground antialiased">
        <ThemeProvider>
          <ToastProvider>
            {children}
            <Toaster position="top-right" />
          </ToastProvider>
        </ThemeProvider>
      </body>
    </html>
  )
}`}</CodeBlock>

`suppressHydrationWarning` is required because `ThemeProvider` (under the hood: `next-themes`) sets the `class` on `<html>` after hydration.

## 5. First component

<CodeBlock language="tsx">{`import { Button } from '@idcert/ui'

export default function Home() {
  return <Button variant="destructive">Hello world</Button>
}`}</CodeBlock>

## Troubleshooting

**Components render unstyled / no background colors**
Missing `@source` directive in `globals.css`. Tailwind v4 does not scan `node_modules` by default.

**`Cannot find module '@idcert/tokens/styles.css'`**
Run `npm i` again, or verify `@idcert:registry` points to the right registry.

**Peer dependency warnings on install**
Install missing peers explicitly: `npm i react-hook-form zod date-fns react-day-picker`.

**Token CSS variables undefined (e.g. `--destructive` empty)**
Missing `@import '@idcert/tokens/styles.css';` before the preset import — order matters.
