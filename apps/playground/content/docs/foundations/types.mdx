Some component props accept long string-literal unions inherited from React's
HTML attribute types — `autoComplete`, `type` on `<input>`, ARIA `role`. Listing
every literal inline in each PropsTable would dwarf the surrounding signal, so
those props link here instead. The union members below are sourced from
TypeScript directly, regenerated on every build.
